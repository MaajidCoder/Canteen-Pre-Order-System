# College Canteen Pre-Order System

A full-stack MERN application for college canteens to reduce queues and improve efficiency.

## Tech Stack
- **Frontend**: React, Vite, Lucide-React, Axios, Socket.io-client
- **Backend**: Node.js, Express, MongoDB, Mongoose, JWT, Socket.io
- **Styling**: Vanilla CSS with a Premium Design System
